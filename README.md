# Student Performance Analysis

## CodeAlpha Data Analytics Internship

### 1. Project Overview
Student Performance Analysis is a Data Analytics project that explores student academic performance using Python.

The project analyses student information, study time, gender, absences and examination grades to understand factors related to academic performance.

### 2. Objective
- Analyse student academic performance.
- Identify average, highest and lowest grades.
- Study the relationship between study time and grades.
- Compare performance based on gender.
- Visualize data using graphs.

### 3. Dataset
The dataset is obtained from the UCI Machine Learning Repository.

Dataset: Student Performance (Mathematics)

- Total records: 395 students
- Total columns: 33
- Missing values: 0

### 4. Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

### 5. Project Steps
1. Import Python libraries.
2. Load the student dataset.
3. Explore dataset information.
4. Check missing values.
5. Calculate average student grades.
6. Analyse gender-wise performance.
7. Analyse study time and grades.
8. Create visualizations and a correlation heatmap.
9. Identify important findings.

### 6. Key Findings
- Total students: 395
- Average final grade: 10.42
- Highest final grade: 20
- Lowest final grade: 0
- Missing values: 0

### 7. Visualizations
The project includes:
- Average Student Grades
- Gender-wise Student Performance
- Study Time vs Student Performance
- Correlation Heatmap

### 8. Conclusion
This project helped analyse student academic performance using Python.

The visualizations help explore the relationship between study time, gender and final grades. The analysis also provides useful insights into student performance.
